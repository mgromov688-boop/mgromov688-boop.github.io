Claude Code с нуля: что это и как работает

19.10.2026 · AUREUS | Нейросети

Claude Code читает файлы проекта, меняет их и запускает команды по твоей просьбе. Ты описываешь задачу обычными словами: объяснить чужой проект, поправить текст на сайте или найти ошибку. Чтобы разобраться, что такое Claude Code и как он работает, начни с маленькой задачи, результат которой сможешь проверить сам.

Здесь пройдём путь от установки до первой правки. Для начала хватит папки проекта и конкретной просьбы. Сложные подключения оставим на потом)

Цены, команды и требования приведены по фактуре, собранной из официальной документации 19.10.2026. Наш опыт AUREUS отмечен отдельно.

Что такое Claude Code простыми словами

Claude Code от Anthropic называют агентом для работы с кодом. Слово «агент» здесь означает, что помощник умеет действовать: прочитать файлы, предложить изменения, внести их и выполнить команды. Ты задаёшь ему работу в переписке.

Попроси Claude изучить папку сайта, найти страницу и заменить заголовок. При первой небольшой правке он покажет изменение и спросит разрешение. Ты видишь, что он собирается поменять. Сначала изучить проект, потом менять: эту привычку стоит завести сразу.

Что умеет Claude Code и кому пригодится

Разработчик может поручить ему исправить ошибку в нескольких файлах, написать тесты или подготовить изменения в Git. Git похож на журнал версий проекта, где хранятся правки.

Но начинать с разработки большого приложения необязательно. Вот примеры задач, с которыми можно знакомиться с Claude Code:

  • Разобраться в готовом сайте. Попросить объяснить, где лежат страницы и какой файл отвечает за нужный текст.
  • Поправить текст. Найти заголовок в файлах проекта, заменить его и посмотреть, что изменилось.
  • Описать затык. Например, после неверного пароля видишь пустой экран. Поручить изучить причину, а затем предложить исправление.
  • Работать с подключёнными сервисами. Через MCP доступны внешние инструменты, в том числе Google Drive, Jira и Slack. MCP здесь как переходник между Claude и инструментами сервиса.

Наш опыт AUREUS: мы каждый день работаем в Claude Code на Windows. Используем его для монтажа рилсов, работы с ботом и публикаций. Это наш рабочий набор задач, а не обещание, что сразу после установки у тебя появится готовая студия монтажа. Для конкретной работы нужны подходящие инструменты и настройки.

Где работает Claude Code

Выбери привычное окно для работы:

  • Терминал. Окно, в котором ты вводишь команды текстом. Как строка переписки с компьютером: написал команду, получил ответ.
  • Редакторы кода. Есть расширения для VS Code и JetBrains, в том числе работа в Cursor.
  • Приложение для компьютера. В нём есть вкладка Code. На Windows x64 и ARM64 приложение уже содержит Claude Code, отдельно ставить CLI не надо. CLI означает запуск через командную строку.
  • Браузер. Можно работать через claude.ai/code.
  • Мобильное приложение Claude. На iOS и Android доступна работа с облачными задачами.

Дальше используем терминал. Приложению для компьютера тоже нужна платная подписка.

Сколько стоит Claude Code

Claude Code входит в Pro, Max, Team и Enterprise. Ещё один вариант доступа: аккаунт Console с оплатой API заранее. На плане Claude Free Claude Code нет.

По данным на 19.10.2026:

ПланЦена и условия
Pro$20 в месяц при помесячной оплате, $17 в месяц при годовой ($200 сразу). Claude Code входит.
Maxот $100 в месяц, 5x или 20x лимитов Pro; включает $100-200 в месяц кредитов API.

Обрати внимание на оплату Pro за год: $200 сразу, а не отдельное списание $17 каждый месяц. Для Team и Enterprise здесь цены не приводим. В собранной для статьи фактуре их нет.

Как установить Claude Code: коротко

Для локальной работы требования такие: Windows 10 версии 1809+ или Windows Server 2019+; macOS 13+; Ubuntu 20.04+, Debian 10+, Alpine 3.19+. Память от 4 ГБ, процессор x64 или ARM64. Нужен интернет. Оболочка: Bash, Zsh, PowerShell или CMD. Страна должна быть из списка поддерживаемых Anthropic.

Ниже короткий путь для Windows. Права администратора не нужны. Подробный разбор и помощь с ошибками вынесли в пошаговую установку Claude Code на Windows.

Установка через PowerShell

Открой PowerShell. Его строка начинается с PS C:\. Вставь команду:

irm https://claude.ai/install.ps1 | iex

Установщик ничего не показывает, пока скачивает. Это нормально. После окончания открой новое окно терминала и проверь установку:

claude --version

В ответе должен появиться номер версии и «(Claude Code)». Для подробной диагностики установки и настроек без запуска сессии есть команда:

claude doctor

Если после установки система не находит Claude, причина может быть в PATH. Это список папок, в которых компьютер ищет программы, как адресная книга для команд. В документации этот случай разобран в разделе Fix your PATH.

Git for Windows рекомендуется: он даёт Git Bash для выполнения команд Bash. Без Git Claude Code использует PowerShell.

Первый запуск: открой папку и войди в аккаунт

Выбери папку знакомого проекта, например небольшого сайта, где сможешь проверить правку.

В терминале перейди в нужную папку:

cd путь\к\проекту

Вместо путь\к\проекту подставь путь к своей папке. Затем запусти Claude Code:

claude

При первом запуске вход проходит через браузер. Используй аккаунт подписки или Console. Дальше вход сохраняется.

Команды запуска вводятся в терминале, а просьбы к Claude уже внутри его сессии. Например, после запуска можно написать: «Объясни структуру папок». Это и будет твоя первая рабочая задача.

Claude Code: обучение на русском в 7 первых уроках

Примеры просьб ниже составлены для обучения по рекомендациям документации. Это задания для тебя, а не отчёт о выполненном тесте.

Урок 1. Узнай, что делает проект

  1. Запусти Claude Code в папке проекта.
  2. Напиши: «Что делает этот проект? Объясни простыми словами. Пока ничего не меняй».
  3. Прочитай ответ и сопоставь его с тем, что знаешь о проекте.

Результат урока: короткое описание проекта. Незнакомые слова попроси пояснить на примере того, что увидит пользователь.

Урок 2. Найди нужный файл

Теперь напиши: «Объясни структуру папок. Найди, где хранится текст главной страницы. Покажи путь к файлу, ничего не меняй».

Для проекта без сайта выбери другой знакомый текст, например описание проекта. Открой указанный файл и найди фрагмент сам. Проверка простая: текст действительно там лежит. Если Claude указал другое место, уточни запрос.

Урок 3. Попроси одну небольшую правку

  1. Выбери короткий заголовок или фразу в найденном файле.
  2. Напиши, какой текст заменить и что поставить вместо него.
  3. Добавь: «Меняй только этот фрагмент. Остальное оставь как есть».
  4. Посмотри предложенную правку и дай разрешение, если она совпадает с задачей.

В первой небольшой правке Claude покажет изменение и спросит разрешение. Режим разрешений переключается сочетанием Shift+Tab. Для этого урока оставь проверку правки за собой: цель в том, чтобы понять, на что ты соглашаешься.

После изменения открой файл. Новый текст должен быть на месте. Пока выбирай то, что умеешь проверить без помощи программиста.

Урок 4. Опиши ошибку так, чтобы её можно было искать

Возьми конкретную проблему проекта. В документации пример такой: «почини вход, где после неверного пароля пустой экран», а не «почини баг».

Для тренировки раздели просьбу:

  1. Опиши своё действие и что появляется после него.
  2. Попроси сначала изучить код и объяснить возможную причину.
  3. Затем попроси предложить маленькое исправление.
  4. После согласованной правки повтори исходное действие и посмотри на результат.

Если у тебя сейчас нет такой ошибки, пропусти задание до реального случая. Придумывать поломку ради галочки смысла нет. Здесь важна привычка: писать, где именно затык и что ты видишь, вместо общего «ничего не работает».

Урок 5. Разбей большую задачу на шаги

Вернись к своему проекту и выбери задачу шире одной фразы. Например, привести тексты страницы к одному стилю. Пока попроси только план: «Изучи тексты этой страницы. Предложи порядок правок, чтобы я мог проверить каждый шаг. Файлы пока не меняй».

Прочитай план и выбери первый пункт. Поручи выполнить только его, затем проверь результат. К следующему переходи после проверки.

Урок 6. Вернись к прошлому разговору

Заверши сессию командой внутри Claude Code:

/exit

В той же папке введи в терминале:

claude -c

Эта команда продолжает последний разговор в папке. Если нужно выбрать другой прошлый разговор, используй:

claude -r

После возвращения попроси напомнить, на какой правке вы остановились. Сравни ответ с файлом, который менял.

Урок 7. Освой справку и короткий запрос

Внутри Claude Code открой справку:

/help

Посмотри доступные команды. Отдельно попробуй короткий запрос из терминала:

claude -p "вопрос"

Вместо слова «вопрос» напиши свою просьбу, сохранив кавычки. Эта команда даёт один ответ и выходит. Для обычной работы с обсуждением правок возвращайся к запуску сессии:

claude

CLAUDE.md и скиллы: чтобы меньше повторяться

CLAUDE.md в корне проекта содержит правила, которые Claude читает в начале каждой сессии. Корень здесь означает главную папку проекта. Файл похож на записку для того, кто пришёл работать: как отвечать, что учитывать и о чём договориться до изменений.

Например, для учебного проекта можно записать такие правила:

Отвечай по-русски. Перед правкой объясни, какой файл хочешь изменить. Если задача состоит из нескольких шагов, сначала предложи порядок работы.

Это пример содержания, а не обязательный шаблон. Наш опыт с русским языком относится и к этому файлу: правила в CLAUDE.md пишем на русском.

Начни с правил, которые понадобились в уроках. Если каждый раз просишь объяснять проще, запиши это.

Скиллы пригодятся для повторяемых задач: процесс упаковывается в скилл и вызывается через команду с его именем:

/имя

Это обозначение вызова из документации, а не имя готового скилла. Для своего процесса используй имя конкретного скилла. Пример такого применения у нас разобран в статье про монтаж видео в Claude Code.

Куда двигаться после первых уроков

Выбирай продолжение по своей работе:

  • Застрял на установке: пошаговая инструкция для Windows.
  • Хочешь подключить сервисы: MCP простыми словами и Make.
  • Интересен монтаж: скиллы для видео в Claude Code.
  • Хочешь разобраться с видео кодом: HyperFrames и Remotion.

Лучше пройти один путь под свою задачу. Если сейчас нужно поправить сайт, монтаж и внешние сервисы спокойно подождут)

FAQ

Claude Code: что это и как работает?

Это агент Anthropic для работы с кодом и файлами проекта. Ты описываешь задачу обычными словами, а Claude Code читает файлы, предлагает и вносит правки, запускает команды. Начинать удобнее с изучения проекта и одного небольшого изменения.

Можно ли использовать Claude Code на русском?

В нашем опыте AUREUS да: пишем задачи по-русски, получаем русские ответы и работаем с русскими текстами. CLAUDE.md тоже пишем на русском. Отдельную официальную страницу о поддержке русского языка мы не нашли.

Сколько стоит Claude Code и есть ли он на Free?

На Claude Free его нет. Pro стоит $20 в месяц при помесячной оплате, $17 в месяц при годовой ($200 сразу). Есть Max, Team, Enterprise и вход через Console с оплатой API заранее. Данные для статьи собраны 19.10.2026.

Как запустить Claude Code после установки?

Открой терминал в папке проекта и выполни:

claude

При первом запуске пройди вход через браузер. Дальше можно попросить объяснить структуру папок или изучить проект перед правкой.

Нужен ли Claude Code только программистам?

Его основная работа связана с кодом, но первое задание может быть понятным без программирования: найти текст в проекте и заменить фразу. Наш опыт AUREUS включает монтаж рилсов, бота и публикации с нужными инструментами и настройками.

С чего начать обучение Claude Code?

С папки знакомого проекта: попроси объяснить её структуру, найди нужный файл и согласуй одну небольшую правку. Затем открой файл и проверь результат. В уроках выше есть примеры просьб и команды, чтобы продолжить разговор позже.
