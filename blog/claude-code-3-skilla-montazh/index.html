Как Claude Code с тремя скиллами собрал рилс без единой ручной склейки

11.10.2026 · AUREUS | Нейросети

Claude Code плюс три скилла с GitHub забрали у меня работу монтажёра. Рилс про них собран ими же: титры, цифры, движение камеры, переходы и звук. After Effects даже не открывали)

Для меня боль сидеть по паре часов над монтажом. Поэтому искал, как контентную часть автоматизировать, и нашёл эту связку. Теперь занимаюсь своими рабочими процессами, а Hermes и Claude Code со скиллами делают ролик.

Что за три скилла

HyperFrames от HeyGen. Оживляет титры, цифры и графики под голос. Claude пишет сцену как веб-страницу, а HyperFrames превращает её в MP4. Открытый код, локальная сборка видео бесплатна.

Remotion. Собирает сцены на React (конструктор, на котором делают сайты), водит камеру по настоящим страницам и кладёт звук. Бесплатно для одного человека и компаний до 3 сотрудников, дальше нужна платная лицензия.

video-shotcraft. 157 приёмов с готовым кодом: наезды, пролёты, переходы, ритм. Открытый код, бесплатно.

Все три лежат на GitHub и обходятся без платной подписки.

Как из них получается ролик

Схема у нас такая. Сначала озвучка. Потом Claude раскладывает её по словам с точным временем, и каждому важному слову достаётся свой кадр: прозвучало «GitHub», на экране значок GitHub, крупно и ровно на этом слове.

Дальше сцены. Настоящие страницы снимаются скриншотами, Remotion летит по ним камерой. Цифры и надписи собирает HyperFrames. Ходы камеры берутся из карточек video-shotcraft. Подробное сравнение HyperFrames и Remotion.

В конце рендер в вертикальное видео и звук эффектов, тише голоса и без повторов.

Наша работа здесь: вкус, текст и правки. Склейки делает Claude.

Где я сам споткнулся

Приём из video-shotcraft лучше просить по исходнику демо, а не по названию. Когда Claude пишет приём «по памяти», вся настройка автора теряется и выходит заметно хуже.

И Remotion при каждом рендере копирует папку с картинками. У меня однажды так забился системный диск в ноль) Теперь папка сборки всегда на диске, где много места.

Частые вопросы

Можно ли монтировать видео в Claude Code?

Да, с тремя скиллами с GitHub: HyperFrames, Remotion и video-shotcraft. Claude Code раскладывает озвучку по словам с временем, на каждое важное слово ставит свой кадр, собирает сцены и рендерит вертикальное видео со звуками. Команды установки всех трёх лежат в гайде в боте @MaximToshaBot.

Что такое HyperFrames?

Это инструмент от HeyGen для титров, цифр и графиков под голос. Сцену пишут как обычную веб-страницу, а HyperFrames превращает её в MP4 и собирает его у тебя на компьютере бесплатно. Код открытый.

Что такое Remotion и зачем он в монтаже?

Remotion собирает видео из сцен на React (на нём же делают сайты). В нашей связке он водит камеру по скриншотам настоящих страниц и кладёт звук. Тоже лежит на GitHub.

Remotion бесплатный или платный?

Бесплатный для одного человека и компаний до 3 сотрудников, команде побольше нужна платная лицензия. HyperFrames и video-shotcraft открытые и бесплатные, а сам Claude Code работает по платной подписке Anthropic.

Может ли нейросеть смонтировать видео автоматически?

Да, почти целиком. Склейки, титры, ходы камеры и звук делает Claude Code со скиллами. На тебе вкус, текст и правки (After Effects мы так и не открыли). Два совета из практики: приём из video-shotcraft проси по исходнику демо, а сборку Remotion держи на диске с запасом места, он при каждом рендере копирует папку с картинками.
