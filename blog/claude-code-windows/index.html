Как установить Claude Code на Windows

19.10.2026 · AUREUS | Нейросети

Вот как установить Claude Code на Windows: выбери команду под своё окно терминала, установи программу и войди в аккаунт. Права администратора не нужны. Ниже пройдём установку, проверим, что всё работает, и разберём затыки с командами и Git Bash.

Claude Code от Anthropic читает файлы проекта, правит их и запускает команды. Задачу ты описываешь обычными словами. У нас в AUREUS он каждый день работает на Windows: помогает с монтажом рилсов, ботом и публикациями. Это наш опыт, а дальше идут шаги из документации.

Команды, требования и цены взяты из официальных материалов, собранных 19 октября 2026 года.

Что нужно для установки Claude Code на Windows

Проверь требования до установки:

  • Windows 10 версии 1809+ или Windows Server 2019+.
  • Память от 4 ГБ, процессор x64 или ARM64.
  • Интернет.
  • Страна из списка поддерживаемых Anthropic.
  • Pro, Max, Team, Enterprise или аккаунт Console с оплатой API заранее.

На плане Free Claude Code нет. Pro стоит $20 в месяц при помесячной оплате, $17 в месяц при годовой ($200 сразу). Claude Code входит. Console с оплатой API заранее тоже подходит для входа, но это другой вариант оплаты.

Для работы понадобятся команды в терминале. Представь окно переписки с компьютером: вместо кнопки вводишь строку, а в ответ видишь результат или ошибку. На Windows в таком окне может работать PowerShell или CMD. Их команды установки отличаются, поэтому сначала посмотрим, что открыто у тебя.

Шаг 1. Открой PowerShell и проверь строку ввода

Открой поиск Windows, набери PowerShell и открой найденное приложение. Запуск от имени администратора для этой установки не нужен.

Посмотри на начало строки, рядом с которой вводятся команды:

  • В PowerShell строка начинается с PS C:\.
  • В CMD с C:\ без PS.

Ориентируйся на строку, а не на цвет окна. Если видишь PS, бери команду для PowerShell из следующего раздела. Если открыт CMD, ниже есть отдельная команда для него.

Само начало строки с адресом папки копировать не нужно. Вставляй только содержимое блока кода и жми Enter. У каждого блока подписано, куда его вставлять)

Шаг 2. Установи Claude Code через PowerShell или CMD

Выбери один способ установки. Все команды подряд запускать не надо.

Команда для PowerShell

Вставь в PowerShell:

irm https://claude.ai/install.ps1 | iex

Установщик ничего не показывает, пока скачивает. Это нормально: пустое окно само по себе ещё не означает ошибку. Дождись окончания установки, затем открой новое окно терминала.

Команда для CMD

Если у тебя CMD, используй эту строку целиком:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

После окончания тоже открой новое окно терминала. Проверка для обоих способов одинаковая, она в следующем шаге.

Эта установка напрямую в Windows называется нативной. Нативная установка обновляется сама в фоне. Отдельный вариант через WinGet тоже есть, но у него обновления устроены иначе.

Альтернатива: установка через WinGet

Для установки через WinGet выполни:

winget install Anthropic.ClaudeCode

Установка через WinGet сама не обновляется. Для обновления используй:

winget upgrade Anthropic.ClaudeCode

Шаг 3. Проверь установку Claude Code

В новом окне PowerShell или CMD введи:

claude --version

В ответ должны появиться номер версии и «(Claude Code)». Это первая проверка: терминал находит установленный Claude Code. Вход в аккаунт будет следующим шагом.

Для подробной диагностики установки и настроек есть отдельная команда:

claude doctor

Она проверяет установку без запуска разговора с Claude.

Если команда не найдена, переходи к разделу с ошибками ниже.

Шаг 4. Открой папку проекта и войди в аккаунт

Проектом может быть папка с файлами, с которыми ты собираешься работать. Перейди в неё из терминала:

cd путь\к\проекту

Здесь путь\к\проекту нужно заменить на адрес своей папки. Это образец команды.

Затем введи:

claude

При первом запуске вход проходит через браузер. Используй аккаунт подписки или Console. Дальше вход сохраняется.

После входа начни с просьбы «объясни структуру папок» или «что делает этот проект?». Так ты сначала дашь Claude изучить файлы, а уже потом попросишь изменения. Для первой правки выбери маленькую задачу: Claude покажет правку и спросит разрешение.

Если нужно сменить аккаунт, внутри Claude Code введи:

/login

Git for Windows: зачем нужен и что делать с Git Bash

Git можно представить как историю изменений проекта. Git for Windows рекомендуется для Claude Code: вместе с ним ты получаешь Git Bash, через который Claude выполняет команды Bash. Bash здесь ещё один способ давать компьютеру команды.

Без Git Claude Code использует PowerShell. Поэтому отсутствие Git само по себе не повод считать всю установку сломанной.

Если Git Bash уже есть, но Claude его не находит, путь можно указать в настройках. На Windows они лежат в %USERPROFILE%\.claude, файл называется settings.json.

В блоке env нужна такая запись:

"CLAUDE_CODE_GIT_BASH_PATH": "C:\\Program Files\\Git\\bin\\bash.exe"

Это фрагмент настроек, не команда для PowerShell и не весь файл. Существующие настройки заменять одной строкой не нужно. Путь должен указывать на твой Git Bash. Здесь приведён путь из документации.

Три ошибки при установке Claude Code на Windows

1. Команда claude не найдена / not recognized

По документации этот затык связан с PATH: папки установки нет в списке мест, где Windows ищет программы. PATH похож на адресную книгу. Если нужной папки там нет, по короткому имени программа не находится.

Сначала проверь, что после установки открыл новое окно терминала, как указано выше. Если ошибка остаётся, нужен раздел Fix your PATH в официальной инструкции Claude Code.

2. The token '&&' is not a valid statement separator

Ты в PowerShell, а вставил команду для CMD. Символы && находятся в CMD-варианте установки выше.

Вернись к началу строки: если там PS, используй команду из блока «Команда для PowerShell». Не нужно вручную переделывать CMD-команду или убирать из неё отдельные символы.

3. 'irm' is not recognized

Обратная ситуация: ты в CMD, а вставил команду для PowerShell.

Либо останься в CMD и возьми команду из блока «Команда для CMD», либо открой PowerShell и используй его вариант.

Нужен ли WSL для Claude Code на Windows

WSL не обязателен. Можно работать напрямую в Windows. Есть и второй путь: WSL 2, то есть Linux-среда внутри Windows.

Разница, которую стоит знать заранее: при нативной установке в Windows песочница не поддерживается, а в WSL 2 есть. Песочница служит для изоляции работы, как отдельная рабочая комната. Если нужна именно она, смотри вариант WSL 2.

Устанавливать и запускать Claude Code в этом случае нужно внутри терминала WSL. Команда для него:

curl -fsSL https://claude.ai/install.sh | bash

Эту команду запускай только внутри WSL, а не в PowerShell.

Вариант без терминала: приложение Claude для компьютера

Если хочется начать без команд, есть приложение Claude для компьютера с вкладкой Code. Оно доступно для Windows x64 и ARM64 и уже содержит Claude Code. CLI отдельно ставить не надо. CLI здесь означает вариант, который запускают командами в терминале.

Для приложения нужна платная подписка.

Что делать после установки

Начни со своей папки и небольшой задачи. Сначала попроси объяснить файлы, потом выбери одну правку. Например, вместо «почини баг» опиши проблему: «почини вход, где после неверного пароля пустой экран». Так Claude получает конкретную задачу, которую можно проверить.

У нас задачи и ответы идут по-русски, русские тексты Claude Code тоже обрабатывает. Это наш опыт, а не заявление об официальной поддержке языка.

FAQ

Можно ли установить Claude Code на Windows без WSL?

Да. Он устанавливается напрямую в Windows через PowerShell, CMD или WinGet. WSL 2 нужен как отдельный вариант, в том числе если тебе нужна песочница: нативная установка в Windows её не поддерживает.

Какая подписка нужна для Claude Code?

Нужен Pro, Max, Team, Enterprise или аккаунт Console с оплатой API заранее. На Free Claude Code нет. Pro стоит $20 в месяц при помесячной оплате, $17 в месяц при годовой ($200 сразу).

Нужны ли права администратора для установки Claude Code?

Нет, права администратора не нужны. Для установки через PowerShell открой обычное окно и используй команду из соответствующего раздела.

Почему Windows не видит команду claude после установки?

Папки установки может не быть в PATH. После установки сначала открой новое окно терминала. Если команда всё ещё не находится, проверь PATH по разделу Fix your PATH в документации.

Обязательно ли ставить Git для Claude Code?

Git for Windows рекомендуется: он даёт Git Bash для выполнения команд Bash. Без Git Claude Code использует PowerShell. Если установленный Git Bash не находится, путь к нему можно указать в блоке env файла settings.json.

Можно ли пользоваться Claude Code без терминала?

Да, в приложении Claude для компьютера есть вкладка Code. Приложение уже содержит Claude Code, отдельно ставить CLI не надо. Нужна платная подписка.
