Make MCP: как подключить Make к Claude Code и что автоматизировать

12.10.2026 · AUREUS | Нейросети

Make MCP позволяет Claude Code запускать твои сценарии Make по просьбе в чате. Ты пишешь «Собери отчёт» или «Выложи ролик», а работу выполняет заранее настроенный сценарий. Запуск доступен даже на бесплатном тарифе Make.

Начни с подключения через окно согласия. Если на входе затык, попробуй адрес с токеном. Но сначала разделим две вещи: запустить готовую автоматизацию и попросить Claude создать её. У Make для них разные условия.

Инструкции и тарифы сверены по документации на 11.10.2026.

Что такое MCP простыми словами

Представь переходник, через который Claude Code подключается к нужному сервису. MCP задаёт правила такого подключения: какие инструменты сервис показывает помощнику и как их вызвать.

MCP-сервер даёт доступ к этим инструментам. В нашем случае это сервер Make. После подключения Claude получает доступ к разрешённым действиям со сценариями, и ты можешь просить выполнить их обычной фразой.

Само подключение ещё не создаёт автоматизацию. Если нужен отчёт по продажам, сначала должен появиться сценарий, который умеет его собирать. Иначе запускать пока нечего.

Что такое Make

Make похож на конструктор: ты соединяешь приложения в цепочку, где каждое выполняет свою часть задачи. Это визуальный сервис в облаке, а собранная цепочка действий называется сценарием.

Как подключить Make к Claude Code

Для Claude Code нужен Node.js. Перед подключением подготовь аккаунт Make и сценарий, который собираешься запускать.

  1. Добавь сервер Make. Открой терминал и выполни команду:

    claude mcp add --transport http make https://mcp.make.com

  2. Открой Claude Code. В терминале введи:

    claude

  3. Начни вход в Make. Внутри Claude Code введи /mcp. В окне согласия выбери организацию Make и скоупы, то есть разрешения, которые даёшь подключению.

  4. Проверь инструменты. Напиши Claude: «Какие инструменты у тебя есть от Make?». Так ты увидишь, что ему доступно, прежде чем поручать работу.

  5. Проверь сценарий. Через MCP видны включённые сценарии (active) или сценарии с запуском по требованию (on-demand). Если нужного сценария нет, начни с этих настроек.

Для первого запуска лучше назвать сценарий прямо, а не писать просто «сделай всё». Например: «Запусти сценарий сбора отчёта по продажам». Claude должен понимать, какую именно работу ты ему поручаешь.

Если вход не работает: подключение по адресу с токеном

Если застрял на входе через окно согласия, есть другой способ: адрес Make с токеном. Токен секретный, как пароль. Его нельзя кидать в переписку, показывать на скриншотах или публиковать вместе с командой.

  1. В Make открой меню со своим именем справа вверху.

  2. Перейди в Profile → API access → Tokens → Add token.

  3. Выбери скоуп mcp:use, заполни Label и жми Add.

  4. Собери адрес вида https://<зона>/mcp/u/<токен>. Зона выглядит, например, как eu2.make.com. Подставь свою зону и свой токен.

  5. Используй команду подключения с этим адресом:

    claude mcp add --transport http make https://<ЗОНА>/mcp/u/<ТОКЕН>

Угловые скобки здесь обозначают места для замены. До запуска команды замени их вместе с текстом внутри на свои значения. Готовую строку с настоящим токеном оставь у себя.

После подключения снова спроси: «Какие инструменты у тебя есть от Make?».

Если запустил сценарий, а ответа пока нет

У ожидания есть лимит: 25 секунд при входе через OAuth и 40 секунд при подключении с токеном. OAuth здесь тот самый вход через окно согласия.

Если время вышло, сценарий продолжает работать, а результат можно забрать позже. Поэтому сообщение о таймауте ещё не значит, что вся задача упала. Не спеши запускать её повторно, особенно если она публикует ролик.

Make MCP и Codex

Codex поддерживает HTTP-серверы. Для подключения используется файл ~/.codex/config.toml, блок [mcp_servers.make] и поле url с адресом токена:

[mcp_servers.make]
url = "https://<ЗОНА>/mcp/u/<ТОКЕН>"

Подставь свою зону и токен, как в разделе выше. Этот адрес тоже нужно хранить в секрете.

У Make нет отдельной страницы подключения к Codex: этот конфиг собран из документаций Make и OpenAI, живьём мы его не проверяли.

Make бесплатно: тарифы Make и ограничения MCP

У Make есть Free за $0 без ограничения по сроку. В него входят:

  1. 1 000 кредитов в месяц.
  2. 2 активных сценария.
  3. Интервал запуска по расписанию 15 минут.
  4. Больше 3 500 приложений.

Core стоит $9 в месяц при оплате за год или $10.59 при помесячной оплате. Он включает 10 000 кредитов и интервал запуска по расписанию 1 минуту.

Для MCP важна отдельная граница: запуск сценариев доступен на всех тарифах, а просмотр, создание и правка через инструменты управления только на платных.

То есть для просьбы «Запусти готовый сценарий» можно начать с Free. А если хочешь поручить Claude создание и изменение сценариев через MCP, понадобится платный тариф Make. Интервал расписания и запуск по просьбе в чате тоже стоит различать: это разные способы запустить работу.

3 идеи автоматизации через Make

Эти задачи мы разбирали в рилсе AUREUS. Выбери ту, которую уже делаешь руками: так проще понять, ради чего вообще возиться с подключением)

  1. «Найди информацию». Телеграм-бот получает запрос, а сервисы в Make ищут информацию и помогают её проанализировать. Такого бота можно предлагать компаниям, которым нужен поиск и разбор материалов. Начать стоит с конкретной темы поиска и понятного вида ответа.
  2. «Выложи ролик». Make отправляет ролик с подписью в Instagram, YouTube и TikTok. Мы сами выкладываем рилсы на площадки через сценарии Make. Для старта это понятная задача: есть готовое видео, подпись и список площадок, куда всё должно уйти.
  3. «Собери отчёт». Бот в продажах отвечает клиентам, а Make разбирает базу и собирает отчёт. До сборки сценария опиши, что хочешь получить в отчёте. Иначе можно автоматизировать сбор данных, а потом всё равно разбирать их руками.

Это пример спроса на опытных специалистов, а не обещание дохода после подключения MCP. Команда в терминале даёт доступ к инструменту. В вакансии искали тех, кто уже умеет собирать автоматизации.

n8n или Make

Если выбираешь n8n или Make, отталкивайся от задачи. У Make есть визуальный конструктор в облаке, бесплатный тариф и официальный MCP с инструкцией под Claude Code. Для старта по этой статье этого достаточно. Объявлять один сервис лучшим для всех задач смысла нет.

FAQ

Можно ли подключить Make к Claude бесплатно?

Со стороны Make запуск сценариев через MCP доступен на Free за $0. Это условие тарифа Make, а не обещание бесплатного доступа к самому Claude.

Что такое MCP сервер?

Это сервер, который даёт AI-помощнику доступ к инструментам сервиса через MCP. Как переходник между помощником и сервисом. Сервер Make позволяет Claude Code работать с доступными сценариями в пределах выданных разрешений.

Работает ли Make MCP с Codex?

Codex поддерживает нужное HTTP-подключение, поэтому выше приведён конфиг с адресом Make. Отдельной инструкции Make для Codex и нашей живой проверки этой связки нет.

Чем отличается запуск от создания сценариев?

Запуск выполняет уже собранную цепочку действий, а создание и правка меняют саму цепочку. Через MCP запуск доступен на всех тарифах Make, инструменты управления только на платных.

Почему Claude Code не видит сценарий Make?

Включи сценарий (active) или поставь ему запуск по требованию (on-demand). Также проверь организацию и разрешения, выбранные при подключении.

Что делать, если Make MCP вернул таймаут?

Сценарий продолжает работать, результат можно забрать позже. Ждёт он 25 секунд через OAuth и 40 секунд при подключении с токеном.
